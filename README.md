# HSK Invaders

A Space Invaders style roguelike for learning Chinese, covering every HSK 3.0 level with gradual progression.

## How to play

Pick a level. Ships carrying Chinese words descend; the panel at the bottom shows an English meaning. Shoot the ship whose word matches it. Only the front ship in each column can be hit, and only one shot can be in the air at a time. A wrong hit costs a shield and highlights the right answer. Clear 5 waves to win; lose all 3 shields or let the ships reach the red line and the run ends. The results screen lists the words you missed.

The game borrows from what research says works for learning Chinese (see the project's `research/learning-methods.md`):

- **Wrong hits teach the right answer.** The correct ship lights up, its word and pinyin are spoken and shown, the line under the prompt shows how its characters are built, and the formation holds still for a moment.
- **Character components.** The first time you hit a word, and whenever you miss one, the game breaks its characters into parts (妈 = 女 woman + 马 sound mǎ).
- **Tone pairs.** Wave 3 of every sector is a tone wave: ships carry tone patterns (mā má, 1 · 2), the prompt is a two-syllable word, and you shoot its tones. Tap the prompt to hear the word again.
- **Word memory.** Every answer is saved in the browser. A word you get right comes back after 1 day, then at growing intervals; a miss sends it back to the start.
- **Typing the pinyin.** Once a word has lasted 7 days, shooting is no longer enough: the prompt asks you to type its pinyin (tones optional). The shot locks on to the ship you typed, so you have to recall the sound, not just recognize the shape. This needs a keyboard; touch-only players keep shooting.
- **Daily patrol.** The title screen offers a short run of only the words due for review, across all levels (press P).

- Keyboard: ←/→ or A/D to move, Space to fire, M to mute, Esc to quit. On a "type the pinyin" prompt, type letters to lock on (Enter forces it, Backspace corrects); A, D, M and Space are letters there, so use the arrows to move.
- Touch or mouse: tap a ship to fly under it and fire; tap elsewhere to move.

## Develop

```sh
npm install
npm run dev        # local dev server
npm test           # unit tests
npm run build      # type-check and production build
npm run build:data # regenerate public/data/hsk from the vocabulary source
npm run build:hanzi # regenerate public/data/hanzi.json (character components)
```

## Word data

`public/data/hsk/{1..7}.json` holds the HSK 3.0 exam syllabus word lists (the finalized Nov 2025 syllabus; level 7 is the combined 7–9 band), one file per level, sorted by word frequency. Each word has `hanzi`, `trad`, `pinyin`, `gloss` (a short English prompt, 30 characters or fewer), `meanings`, `pos` and `freq`. `index.json` lists per-level counts.

The files are generated by `scripts/build-data.mjs` from a pinned commit of [drkameleon/complete-hsk-vocabulary](https://github.com/drkameleon/complete-hsk-vocabulary).

| Level | Words | Cumulative |
|---|---|---|
| HSK 1 | 294 | 294 |
| HSK 2 | 197 | 491 |
| HSK 3 | 487 | 978 |
| HSK 4 | 972 | 1,950 |
| HSK 5 | 1,547 | 3,497 |
| HSK 6 | 1,684 | 5,181 |
| HSK 7–9 | 4,876 | 10,057 |

`public/data/hanzi.json` holds component data for the 2,966 characters in those lists: each character's top-level parts, which part carries the meaning and which the sound (where known), plus a short label and pinyin for every part. It is generated by `scripts/build-hanzi.mjs` from a pinned commit of [Make Me a Hanzi](https://github.com/skishore/makemeahanzi).
